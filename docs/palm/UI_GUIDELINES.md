# DIRETRIZES DE INTERFACE

1. **Mostre primeiro, explique depois:** número grande + rótulo curto; a explicação fica no "?".
2. **Uma ação principal por tela**, visível sem rolar.
3. **Listas antes de cartões.** Cartão só para agrupar o que é diferente.
4. **Cor nunca sozinha:** ícone + texto em todo estado.
5. **Vazio/erro/carregando:** o que está vazio, por quê, o que fazer (com botão).
6. **Confirmação só para o irreversível;** no resto, "Desfazer".
7. **Formulário progressivo:** O quê? Quanto? Quando? — o resto em "Mais opções".
8. **Texto:** pt-BR, curto, humano; números em R$ com separador brasileiro.
